# Name and Trademark Use

## The Ferric Oxide name

You may use the name "Ferric Oxide" to refer to this project, in articles, talks, packages, ports and derived projects, as long as the use is accurate and does not suggest that something is an official Ferric Oxide release when it is not. Forks are welcome; please give yours a different name if you distribute it.

## The Redox OS trademark

"Redox OS", the Redox OS logo and related marks belong to the Redox OS nonprofit and are governed by [its trademark policy](https://gitlab.redox-os.org/redox-os/redox/-/blob/master/TRADEMARK.md). Ferric Oxide follows that policy:

- Ferric Oxide does not call itself Redox OS and does not use the Redox OS logo.
- Ferric Oxide is not official Redox OS software and does not claim endorsement by the Redox OS nonprofit.
- Ferric Oxide packages and identifiers must not use the `redox-os-` package namespace or the `org.redox_os.` reverse-DNS prefix.
- The name Redox OS appears in this repository only to credit the upstream project and to name upstream components kept for technical compatibility.

Questions about the Redox OS trademark go to the Redox OS nonprofit at trademark@redox-os.org, not to this project.
