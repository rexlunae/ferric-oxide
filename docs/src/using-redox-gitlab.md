# Working on GitHub

Ferric Oxide lives in one repository:
[github.com/rexlunae/ferric-oxide](https://github.com/rexlunae/ferric-oxide).
It holds the build system, kernel, bootloader, C library, base services,
file system, package tools and this book. You can clone and build it without
an account; you need a GitHub account to file issues or open pull requests.

This chapter covers:

- [Repository Structure](./repository-structure.md): where things live.
- [Creating Proper Bug Reports](./creating-proper-bug-reports.md): what a
  useful report contains.
- [Creating Proper Pull Requests](./creating-proper-pull-requests.md): the
  fork, branch, sign-off and review workflow.
- [Filing Issues](./filing-issues.md): when to open an issue, and which kind.
