# Getting in Touch

Ferric Oxide has no chat server of its own yet. Conversations happen on
GitHub, where they stay searchable and attached to the work they're about:

- **Questions, bug reports and hardware reports:** open an
  [issue](https://github.com/rexlunae/ferric-oxide/issues). See
  [Filing Issues](./filing-issues.md) and
  [Creating Proper Bug Reports](./creating-proper-bug-reports.md).
- **Design proposals:** open an issue labelled `proposal` before writing a
  large change to a kernel interface, a scheme, the file system format or the
  build system layout, so the approach can be agreed first.
- **Code review:** comment on the pull request. Reviewers are notified by
  GitHub; there is no separate room to post a link in.

All project spaces follow the
[Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).

The Redox OS Matrix space is for Redox OS. Please don't ask Ferric Oxide
questions there: the two projects are independent, and Redox's developers
aren't responsible for this fork.
