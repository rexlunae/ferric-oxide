# Contributing

Ferric Oxide is developed on GitHub at
[rexlunae/ferric-oxide](https://github.com/rexlunae/ferric-oxide). Issues,
pull requests and design discussion all happen there.

Before your first contribution, read:

- [CONTRIBUTING.md](https://github.com/rexlunae/ferric-oxide/blob/main/CONTRIBUTING.md):
  license terms, the Developer Certificate of Origin sign-off, what a good pull
  request looks like and where help is most useful.
- The [AI Contribution Policy](https://github.com/rexlunae/ferric-oxide/blob/main/AI_POLICY.md):
  AI-assisted contributions are welcome, with a human accountable for every
  change.
- [AGENTS.md](https://github.com/rexlunae/ferric-oxide/blob/main/AGENTS.md):
  the project rules and Rust conventions, and a map from common tasks to the
  documents and code involved. Despite its name, it is written for human
  contributors as much as for coding agents.

The rest of this section covers [how to get in touch](./chat.md),
[best practices](./best-practices.md), and
[working on GitHub](./using-redox-gitlab.md): the repository layout, bug
reports, issues and pull requests.

Ferric Oxide is a fork of Redox OS, but the projects are separate. Contribute
to Ferric Oxide here, not through Redox's GitLab or chat. Redox does not accept
AI-generated contributions, so never send AI-assisted work from this project
to Redox.
