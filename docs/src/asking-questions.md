# Questions, Feedback, Reporting Issues

- Questions about building and developing are answered in the
  [Developer FAQ](./developer-faq.md) and the rest of this book.
- [Getting in Touch](./chat.md) explains where to ask.

To report a problem or suggest a change, open an issue on the
[GitHub issue tracker](https://github.com/rexlunae/ferric-oxide/issues). The
[Filing Issues](./filing-issues.md) page explains what to include.

Please don't report Ferric Oxide problems to the Redox project: it is a
separate project, and Ferric Oxide's changes are not part of Redox.
